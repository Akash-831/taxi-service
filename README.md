# 🚖 Taxi Service Booking Website

A responsive Taxi Service Booking Website developed using HTML, CSS, JavaScript, PHP, and MySQL. The platform allows users to select their preferred location, choose from multiple vehicle options, and submit booking requests directly through WhatsApp for quick and convenient communication.

## ✨ Features

* Responsive design for mobile, tablet, and desktop devices
* Multiple pickup and destination location options
* Four vehicle categories available for booking
* User-friendly booking form
* Direct WhatsApp booking integration
* Fast and simple ride reservation process
* Modern and clean user interface
* Database connectivity using MySQL
* Dynamic functionality powered by PHP

## 🚗 Vehicle Options

Users can choose from four different vehicle categories based on their travel requirements.

* Hatchback
* Sedan
* SUV
* Tempo Traveller

## 📱 WhatsApp Booking System

When a user completes the booking form:

1. Selects pickup location
2. Selects destination
3. Chooses a vehicle
4. Enters booking details

The booking information is automatically prepared and sent through WhatsApp, allowing direct communication with the service provider.

## 📂 Project Setup

1. Clone the repository

```bash
git clone https://github.com/Akash-831/taxi-service.git
```

2. Move the project folder to:

```text
C:\wamp64\www\
```

3. Create a MySQL database and import the SQL file.

4. Configure database credentials in the PHP configuration file.

5. Run the project using:

```text
https://taxi-service.infinityfreeapp.com/?i=1
```
